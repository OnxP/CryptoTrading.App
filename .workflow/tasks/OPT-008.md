# OPT-008 Evidence verifier agent
Objective: `EvidenceVerifier.run(claims, evidence_store, market_snapshot, model_client)` returns claim-level `ClaimVerification` findings with status in {SOURCE_SUPPORTED, CONTRADICTED, INSUFFICIENT, STALE}, citations, checks performed, severity, unresolved disagreements, expiry. Numerical claims are rechecked by code against snapshot receipts; identity, unit and time-window mismatches are detected by code; the model only drafts the narrative of disagreements. A deterministic `QuarantinePolicy` marks inputs with CONTRADICTED material claims as quarantined for downstream sections.
Current behaviour: none.
Allowed files: options-research/prompts/evidence_verifier/v1.md, options-research/src/options_research/agents/evidence_verifier.py, options-research/src/options_research/policy/quarantine.py, options-research/fixtures/model/evidence_verifier/**, options-research/tests/test_evidence_verifier.py, .workflow/handoffs/OPT-008.md
Forbidden: deleting or smoothing an extreme observation; counting copies of one origin as corroboration; the model producing the numeric verdict.
Acceptance checks:
- Claim "-8% on the day" vs receipt showing -3.1% -> CONTRADICTED with both numbers and the receipt id.
- Claim supported only by 5 syndicated copies -> INSUFFICIENT (independent_sources = 1), not SUPPORTED.
- Claim whose only source is after as-of -> STALE or INSUFFICIENT with the exclusion noted.
- Extreme but internally consistent move (fixture -35% with matching volume) -> not flagged as bad data.
- Quarantine of a claim does not remove the original evidence records.
Risk: L2
Stop conditions: any automatic downstream action beyond marking.
