# OPT-106 Pricing specialist agent
Objective: `PricingSpecialist.run(request, chain_snapshot | None, market_snapshot, news/verification envelopes, model, budget)`. Code selects candidate structures from the approved set using the horizon (nearest monthly expiry at or beyond horizon end) and strikes near spot (config), builds scenario grids and bounds, and compares each with 100 shares of underlying exposure over the same grid and with no trade. Model (mocked) writes one paragraph per structure using only supplied numbers. Output: new finding type `StructureComparison` (legs with OCC symbols, side, one contract-set, quote times, bid/ask, net debit or credit, bounds, scenario table ref, liquidity flags, fees assumption, assignment and exercise caveats, receipt ids). No chain -> ABSTAIN with thesis_only = true; never fabricated legs.
Current behaviour: none.
Allowed files: options-research/prompts/pricing_specialist/v1.md, options-research/src/options_research/agents/pricing_specialist.py, options-research/src/options_research/findings.py (add StructureComparison), options-research/fixtures/model/pricing_specialist/**, options-research/tests/test_pricing_specialist.py, .workflow/handoffs/OPT-106.md
Forbidden: any quantity other than one contract-set; expected return or probability of profit; recommending a direction (direction is an input, stated as such).
Acceptance checks:
- Usable chain: long call, long put, one debit and one credit spread compared; each finding cites receipt ids and quote times; underlying-exposure and no-trade rows present.
- Chain unavailable: ABSTAIN, thesis_only = true, zero legs anywhere in the envelope.
- Expensive-IV fixture: a correct-direction cell shows negative P&L and `caveats` carries the spec sentence that a correct directional thesis can lose money.
- Model output naming a leg not in the input -> ERROR envelope.
Risk: L2
Stop conditions: any field readable as an order instruction outside the advisory wrapper.
