# OPT-104 Tradier option chain snapshot: expirations, chains with greeks, OptionQuote model, quality checks
Objective: `OptionChainSnapshot` from /v1/markets/options/expirations and /v1/markets/options/chains?greeks=true. `OptionQuote`: OCC symbol, underlying, expiry (date plus UTC instant of 16:00 America/New_York), strike, right, bid/ask/last with their epoch-ms times in UTC, sizes, volume, open interest, contract_size, exercise style (American, metadata), settlement (physical), vendor greeks and vendor IV as `vendor_*` fields. Code quality flags per quote: zero_bid, crossed, wide (spread/mid above config), stale (older than max age vs as_of), nonfinite. Snapshot id plus a receipt for the underlying reference price.
Current behaviour: none.
Allowed files: options-research/src/options_research/options/{__init__,chain}.py, options-research/src/options_research/connectors/tradier.py (two methods), options-research/fixtures/cassettes/tradier/**, options-research/tests/test_option_chain.py, .workflow/handoffs/OPT-104.md
Forbidden: filling a missing bid or ask with last or mid; using vendor greeks without the vendor label; naive expiry datetimes.
Acceptance checks:
- Docs-shaped chain cassette yields quotes with correct UTC times and contract_size 100.
- bid 0 -> zero_bid and excluded from usable(); bid > ask -> crossed; old quote time -> stale.
- Expiration not in the expirations list -> ChainUnavailable.
- Snapshot id reproduces for the same cassette and as_of.
Risk: L2
Stop conditions: any aggregation across strikes that invents a missing quote.
