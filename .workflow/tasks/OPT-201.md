# OPT-201 Realised-vol estimators and fixed-weight forecast with receipts
Objective: `options/vol.py`: from a list of complete daily Bars compute close-to-close, Parkinson and Yang-Zhang realised vol (annualised sqrt(252)), EWMA (lambda 0.94) and a HAR-style fixed-weight forecast (0.30/0.40/0.30 on 1/5/22-day Yang-Zhang), each as a CalculationReceipt; `RealisedVolSummary` with forecast, range [min,max], bars_used, window; a `VolForecaster` protocol so a fitted model or Chronos can be plugged in later as a labelled comparison.
Current behaviour: MarketDataSpecialist has one close-to-close realised_vol receipt on 1h bars annualised on a 24h calendar.
Allowed files: options-research/src/options_research/options/vol.py, options-research/tests/test_vol.py, .workflow/handoffs/OPT-201.md
Forbidden: fitting weights on fixture data; any probability; non-finite handling by substitution (missing stays None with a reason).
Acceptance checks:
- Constant-vol synthetic GBM bars: all three estimators within 15% of the true vol over 250 bars; Yang-Zhang variance of estimate lower than close-to-close on 60-bar windows (drift-free).
- Fewer than 2 bars -> every receipt result None with reason; fewer than 22 bars -> HAR uses the available window and says so in assumptions.
- Receipts deterministic (same bars -> same receipt ids); units "annualised fraction".
Risk: L3
Stop conditions: any estimator producing a value from fewer than 2 bars.
Context: OPTIONS_M3_PLAN decisions 1-2.
Status: COMPLETE (see .workflow/handoffs)
